# 🏭 Ilham ERP — Manufaktur

**Sistem Pembelajaran Akuntansi Biaya & ERP Manufaktur**

> ERP manufaktur sederhana berbasis web untuk memahami alur produksi,
> akuntansi biaya, dan harga pokok produksi secara praktis.

---

## 🎯 Tujuan

Media pembelajaran akuntansi manufaktur, mencakup:

- Master Data (BOM, bahan baku, produk jadi, work center)
- Modul Produksi (SPK, pemakaian bahan, BTKL, BOP)
- Akuntansi Biaya (BDP, BOP, HPProduksi)
- Siklus Akuntansi lengkap
- Laporan khusus manufaktur
